# 胡桃法语 · DALF C1

一个可独立部署的法语刷题网站。题库由本次上传的 PDF 和音频整理而成，按长听力、短听力、阅读、写作和口语导航，文章使用法语标题、中文释义与主题标签。考试场次仅作为详情页来源。

已收录全部 117 个附件：81 份 PDF、486 页材料、36 段音频，整理成 176 组练习、547 道交互题，另含 28 组写作和 85 组口语练习。两段只有音频、没有对应 PDF 的资料使用转写摘录和明确标记的补充理解题。

## 启动

需要 Node.js 20.19+ 或 22.12+（当前环境使用 Node.js 24）。

```bash
cd /workspace/wangzhan
npm ci
npm run dev -- --port 5173 --strictPort
```

生产版本：

```bash
npm run build
npm run preview -- --port 4173 --strictPort
```

部署时上传 `dist/` 到支持静态文件的网站托管服务即可。网站采用哈希路由，不需要服务端路由重写。必须同时上传 `content.json` 和 `audio/`，并使用 HTTP/HTTPS 访问，不能直接双击 `index.html`。当前源码与本地运行验证不等于已经部署到公网。

## 已实现

- 按题型、文章主题、法语或中文关键词筛选；收藏、练习记录、错题回顾。
- 独立音频播放器：播放、暂停、拖动、前后跳转 15 秒、0.5–2 倍速。
- PDF 正文提取为网页文字，不嵌入 PDF；法语原文和中文参考译文切换。
- 选择词句后高亮；再次点击可依次切换黄色、紫色、红色，第四次取消高亮。
- 单词与词句备注：红色加粗、悬停提示、独立单词笔记页。
- 每道题独立选择或输入；保留未作答、正确、错误、待自评四种状态。
- 写作原题或明确标注的补充指令在上，下面是输入区；分别保存综合写作和议论文草稿，统计法语词数。
- 85 个口语题目按主题分类，提供法中题目、原文材料、表达提纲和自检清单。
- 计时器、字号调节、移动端导航，以及学习数据 JSON 导出和导入。

## 答案与翻译的边界

客观选择题依据整理后的答案自动核对。填空接受列明的标准表达和精确匹配；不同表述的开放回答留待对照参考要点自评，不采用简单关键词相似度强行判错。判断题可核对判断选项，引用依据需要自评。写作和口语提供草稿、自检与保存，不声称提供 AI 或官方评分。

题目与参考要点已按原资料和正文整理。扫描件可能有水印遮挡或识别误差。没有原题、仅有文章的资料，所补充的理解题明确标注为“补充理解练习”。中文参考译文已使用更新的英中模型重新生成，结合扫描文字修复、专名词表和人工修订；题干与选项也提供中文参考。部分扫描内容仍有识别不清处，法语原材料为核对依据。译文不参与答案评分。

## 数据和隐私

离线学习与内置词库不需要 API 密钥、数据库或登录。查词采用本地优先；本地缺失的词句按弹窗中的开关自动调用Google翻译，也可关闭自动联网并手动查询。仅发送当前查询文字，结果留在本页。练习、草稿、收藏和标注仅写入当前浏览器的 `localStorage`。换设备前请导出学习备份；清理浏览器数据会移除本地记录。题库正文和音频属于网站静态资源，不随学习备份重复导出。

## 内容维护

- `public/content.json`：网站实际使用的题库与参考译文。
- `public/audio/`：用户上传的原始音频；未转码改变音质。
- `data/overrides.json`：逐题整理的题干、选项与参考要点。
- `data/translations.json`：以原段落 SHA-256 为键的中文机器参考译文。
- `scripts/catalog.py`：双语标题与主题分类。
- `scripts/extract.py`、`questions_ocr.py`、`materials_ocr.py`：PDF 文字层修复与 OCR。
- `scripts/curate*.py`、`build_content.py`：题卡整理与静态题库构建。
- `scripts/translate.py`：可选的本地参考翻译脚本，应用启动和构建不依赖此步骤。

PDF 原件在当前工作区的 `/workspace/attachments`，不会被复制到网站或部署产物。重新导入原始 PDF 需 Python 的 PyMuPDF、Pillow、NumPy、Tesseract 与法语语言数据。日常开发、启动和部署直接使用已生成的题库，不需要重新运行 OCR 或下载语言模型。

本项目没有执行 Git 推送或公网发布。

## 双击打开的离线版本

运行 `npm run build` 后执行 `python3 scripts/package_standalone.py`，会生成 `../wangzhan-release/胡桃法语-DALF-C1-双击打开.html`。它将样式、程序、完整题库和 36 段音频嵌入同一个文件，可用桌面 Chrome 或 Edge 直接打开，无需解压、联网或启动服务器。文件较大，首次打开需要稍等。项目目录与`wangzhan-release/`中均生成同名双击文件。浏览器学习记录与线上版本分别存储，换版本前请导出备份。


## 本次更新：释义与可编辑范文

听力、阅读的全部547道题均新增中文答案原因和对应法语证据句。提交整组练习后，在“法语原文”“中文参考译文”之后打开“参考答案释义”，可点击段落链接定位原文。开放题继续保留自评，不因匹配关键词而强行判错。

28组写作各含Synthèse与Essai范文；85组口语各含Monologue和6组Débat追问。范文依据本次用户提供的五份DOCX模板组织，使用统一连接句和段落顺序，主题论据保存在`data/model-profiles.tsv`及`data/synthese-notes.tsv`。写作训练目标约20/25，口语约14/25，范文不构成实际得分保证。口语第1套第24题原标题与正文不符，已更正为缩短工作时间。

“编辑范文”支持直接增删、加粗、下划线、斜体、黄色或紫色高亮、清除格式及撤销。修改按题目和范文类型分别自动保存在当前浏览器；即使清空全文也会保存。恢复原文只作用于当前范文，需确认。全部编辑随学习备份导出与导入；旧版备份仍可导入。

默认计时：写作150分钟，阅读50分钟，口语30分钟。左下胡桃标志已扩大。当前工作区的单词笔记功能没有每日数量上限。

547道题干和705个选择题选项均重新人工编写了中文译文；文章参考译文已重新生成并对重点篇目润色。专名保留原文，扫描中无法可靠辨认的片段保留提示。

维护流程：`PYTHONPATH=/workspace/tooling/python python3 scripts/refresh_references.py`会按顺序应用正文与答案修复、生成范文和逐题释义、合并译文（需本地内容维护依赖）。翻译构建是可选的离线工作，使用`scripts/translate_references_v3.py`及`merge_references.py`；日常启动、构建和使用不需要翻译模型。不要重新执行旧的`build_content.py`后直接覆盖已修订的题库。

验证包括`npm test`、`npm run build`、`python3 tests/browser_smoke.py`及`python3 tests/reference_browser.py`。后两项需运行本地服务器与Chromium；新增测试也可通过`NOIX_TEST_URL=file:///绝对路径/胡桃法语-DALF-C1-双击打开.html`检查双击版本。

## 本次细节更新：站内词句查询

原文选词工具条新增“查词 / 译句”；题目、范文和答案中的法语文字也可选择后查询。“单词与笔记”内另有“打开词典”，可直接输入单词、短语或句子。结果按n.、v.、adj.、adv.等区分释义，支持变位、阴阳性、复数、省音形式、短语组成词、搭配和相关词族。法语重音保留，pêche与péché等不同词不会被强行合并。

词典采用Wiktionary的中英版本、词形资料和经过整理的C1短语。缺失的英文版释义及课文句子在本地补译；不把机器译文视为人工核订的专业词典。未收录的新表达可在同一弹窗联网补充，无需打开外部网页。联网服务受网络和服务方可用性影响，失败会显示重试提示，本地词库不受影响。最近100次联网结果缓存在当前浏览器，该临时缓存不属于学习备份。

个人单词本现在只展示备注非空的词句，已有普通高亮保留在正文中。单词本支持编辑备注；删除备注不删除普通高亮。正文工具条的“删除高亮”也不会删除备注，并支持删除所选范围内的部分或重叠高亮。旧备份继续兼容。

维护入口：`scripts/build_dictionary.py`提取离线词库与词形资料，`translate_dictionary.py`补充缺失释义及句子缓存，`finalize_dictionary.py`合并人工短语、词族与许可信息。日常构建直接使用`public/lexicon.json`；双击版会内嵌这份词库。数据来源、修改说明和许可见`data/dictionary/NOTICE.md`。新增浏览器验证：`python3 tests/lookup_browser.py`；联网服务使用拦截响应测试，不向第三方发送测试内容。
