# 胡桃法语 · DELF B2

根据 `hakseup/wangzhan` 的 `noix-dalf-c1` 分支（8ddce8333ef648984fe2f48305bc8c6a08139ca3）制作的独立 B2 版本。首页采用黄橙色、晨雾凯旋门、咖啡与笔记本背景；保留原版导航、手写字体、品牌标志、双栏练习、手动高亮、笔记、收藏、复盘、草稿、范文编辑、单词复习和备份功能。

## 使用

普通使用直接用 Chrome 或 Edge 打开随附的 **胡桃法语-DELF-B2-双击打开.html**，无需安装依赖或启动服务器。请先下载文件到电脑，再打开；不要在网盘或聊天附件预览器中使用。

学习进度保存在当前浏览器，使用独立的 B2 存储键。请通过「学习设置与备份」定期导出 JSON，换浏览器或电脑时再导入。部分浏览器限制 `file://` 下的存储；若页面提示存储失败，请导出备份，或使用下面的本地服务器方式。

共 300 组练习，听阅共 673 个可独立作答项（包含判断题子项）。口语按教育、职业职场、社会生活、男女问题、科技影响、生态、健康七个主题展示。

考试场次依据附件《【必看】考频表（带水印）.pdf》；重复场次保留，未标注的题目按用户要求显示「国外考过，国内暂未考过」。已补充12段 B2 原声录音（7段长听力、5段短听力），按录音内容与题目对应；另已加入《法国森林面积减少》的合成练习音频，其余21组听力标注「本题暂未收录音频」。2021年5月文件对应 CITES，考试场次仍按考频表展示。所有听力均在提交后开放原文。

写作采用 B2 的单篇写作、不少于 250 词、建议 60 分钟。16 篇参考范文来自附件《写作范文.pdf》；慈善跑步题的参考范文按附件格式另行编写并标明。口语每题包含根据附件材料和陈述、辩论模板编写的示例，使用共同结构与主题论据，不是官方答案。参考范文均可编辑、导出。

## 内容与验证边界

- 扫描件经过文字识别和题号、选项整理，少数字形仍可能存在识别误差。已移除原始文字折叠入口。明显乱码和水印已清理，三篇问题阅读已重新核对原 PDF；原附件本身缺失的半句话明确标注缺失。
- 已核实的客观答案自动核对；缺少可核实答案的题目留作自评。《家庭作业争议》附件没有答案页，未人为补成官方答案。开放题允许同义表达，需要结合材料自评。
- 听阅正文、题目和选项的中文由本地模型生成，页面注明机器参考译文。口语和写作所附中文优先保留附件译文。
- 复盘提供逐题解析和原文定位。已核对引文用实线标注，自动匹配的候选位置用虚线与问号标注，并明确提示待核对；不把匹配结果作为自动评分依据。正文按句重整参考译文；原附件译文和人工核对段落保留，机器参考部分仍有局限。
- 已完成生产构建及题库、评分、标注、词书等自动检查。本次未进行浏览器视觉与交互实测。本版本保存到 GitHub 的独立 `noix-delf-b2` 分支，下载区提供同版离线包。

## 源码运行

需要 Node.js 20.19+ 或 22.12+：

```bash
npm ci
npm run dev
npm test
npm run build
python scripts/package_offline.py
```

`dist/` 是可部署到静态托管服务的目录，采用哈希路由。`index.html` 是开发入口，不能直接双击；离线交付文件由打包脚本嵌入全部题库、字体、图片和应用代码。

词典沿用参考仓库的词典来源与许可，按 B2 语料筛选，并重新建立 B2 词书来源。许可与署名见 `data/NOTICE.txt`、`data/CC-BY-SA-4.0.txt` 及题库中的 `lexicon.attribution`。DOMPurify 源文件及其许可声明保留于 `src/vendor/`。

阅读判断题已统一为 Vrai/Faux 选择加独立 Justification 输入框，多条判断拆为 a/b/c 子项并保留原题号；扫描文本修复记录见 data/tf-ocr-repair-audit.json。

2026年6月口语附件共15题均已标注。补充题：第1题归入社会生活，第8题归入科技影响，第10题归入社会生活；各含原文、逐段中文翻译、陈述范文和辩论问答。
