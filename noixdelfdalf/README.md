# 胡桃法语 · 学习平台（noixdelfdalf）

把「胡桃法语 DALF C1」和「胡桃法语 DELF B2」两个刷题网站合并成一个完整的法语学习平台。平台分为四个板块：

| 板块 | 法文副标题 | 主题色 | 内容 |
| --- | --- | --- | --- |
| 系统学习 | Apprendre | 鼠尾草绿 `#5f7759` | 分级语法课（A1–C1）、主题词汇单元，每个知识点都有配套练习 |
| 阅读精听 | Lire & écouter | 雾蓝 `#566d8e` | 每日法语新闻与原声音频、点词查义、划线标注、逐句听写、生词本 |
| 题库练习 | S’exercer | C1 紫 `#735a78` / B2 琥珀 `#a6752f` | 现有 DELF B2（313 组）与 DALF C1（252 组）题库，A2、B1 待补充 |
| 找老师 | Professeurs | 玫瑰陶土 `#a65f58` | 浏览老师、视频介绍、学员评价、按时段预约、课后笔记同步 |

## 当前阶段：设计稿

`designs/` 里有 20 张页面设计（1440 × 900，PNG 为 2× 高清）：

- `01–04` 首页：首屏、四个板块、今日学习、真题题库与老师
- `11–14` 系统学习：学习总览、语法课、配套练习、主题词汇
- `21–24` 阅读精听：今日报亭、文章精读（点词查义）、逐句精听与听写、生词本
- `31–34` 题库练习：选择等级、DALF C1 题库、练习工作台、DELF B2 复盘
- `41–44` 找老师：浏览老师、老师主页、预约时间、我的课程

打开 `designs/index.html` 可以浏览全部缩略图；`designs/overview.jpg` 是 20 张设计稿的总览图。

### 修改与重新生成

设计稿由 `designs/src/*.py` 生成 HTML，样式共用 `designs/html/noix.css`。

```bash
cd designs/src && python3 build.py
```

生成的 `designs/html/*.html` 可直接用浏览器打开。截图时使用 Playwright，视口 1440 × 900，deviceScaleFactor 2。

## 视觉延续

沿用 C1 / B2 现有网站的字体与元素，重新组织成统一的平台：

- **字体**：Journal（Mansalva 的轻度修正版，SIL OFL 1.1）用于法文手写标题；Georgia 斜体用于法文副标题与原文；宋体（Songti SC / Noto Serif SC）用于中文展示标题；PingFang SC 用于正文。
- **品牌**：胡桃 Logo、胡桃棕 `#7a4b2e`、口号 *Un petit pas chaque jour*。
- **图像**：C1 的「塞纳河雾中铁塔」与 B2 的「凯旋门晨光咖啡」两张背景图，分别作为两个题库的封面。
- **交互**：保留 C1 的双栏练习工作台、黄 / 紫 / 红三级高亮、红色加粗单词备注，以及 B2 复盘里实线（已核对）和虚线（候选）原文定位。
- **变化**：从左侧固定导航改为顶部导航，加上各板块自己的左栏；四个板块各用一种主题色区分，共用一个生词本和学习记录。
