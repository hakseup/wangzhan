# 1.0.3 内容校订记录

本次覆盖全部313篇练习、511个正文段落：68篇旧机翻重新翻译，其余245篇已有译文逐篇对照法语复核。正文及脚注共312段有翻译修订；673道题干与969个选项重译，另修正53条含乱码的词典记录。

所有正文revision使用原法语SHA256锁定来源。对照PDF恢复26段原文，包括双栏阅读顺序、OCR缺字与无关脚注污染；45道题干和60个选项的法语抽取错误亦附有PDF核对记录。题号、题型、选项ID、评分答案值保持一致。

`revisions/` 为逐篇段落与逐句中文；`questions-*.json` 为题干、选项及已核实的法语修正；`reviewed-audit-*.json` 为已有译文的逐篇复核记录；`dictionary-fixes.json` 为词条修正；`audit.json` 由构建程序生成。

原PDF本身存在的留空、残句或术语疑点不擅自编补。巴黎小园丁两处留空在译文中明确标记；其他源文疑点参见各revision及复核记录。CITES原稿将短吻鳄个体数量写为espèces，译文保留语境并注明原词，法语未擅改。

构建命令 `npm run build:cloud` 会验证来源哈希、单位数量、题目和选项数量，清理HTML实体及CJK偏旁误识别，生成需要开通权限的 `/api/content-revisions` 分批响应。分批文件不进入静态网站，不覆盖用户进度。复盘答案引用重新定位到修复后的原文，未经人工确定的旧参考定位不提升为已核对答案。

验证：44项自动测试，包含所有正文字符完整性、答案值与题号保留、受保护内容分批加载、新版一致性和排序；独立浏览器环境验证存档恢复；320、375、390、768、1440、2560、3440像素宽度验证首页全部入口、导航、排序与横向溢出。
