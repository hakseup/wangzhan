# French–Chinese lookup data

Dictionary text, parts of speech, inflected spellings and explicit derivations are
adapted from Wiktionary, via Kaikki and Wiktionary-to-Yomitan (2025-04-08).

Public source archives:
- https://github.com/yomidevs/wiktionary-to-yomitan/releases/download/v2025-04-08-10-54-36-00-00/kty-fr-zh.zip
- https://github.com/yomidevs/wiktionary-to-yomitan/releases/download/v2025-04-08-10-54-36-00-00/kty-fr-en.zip
- https://zh.wiktionary.org/ and https://en.wiktionary.org/
- https://kaikki.org/

The adapted dictionary is provided under CC BY-SA 4.0; Wiktionary also provides
text under GFDL where applicable. See CC-BY-SA-4.0.txt. Attribution, history and
contributors for an individual headword are available in its Wiktionary page
history. These source URLs are attribution information, not runtime services.

Changes: plain text extraction, simplified Chinese conversion, merging of senses
by part of speech, inflection and derivation indexes, selected corpus usage
examples, reviewed idioms and families. Missing senses from the English edition
and corpus sentence references are translated locally using Argos models.
These supplementary translations are machine translations, not a professionally
reviewed dictionary or certified translation.

With online supplementation enabled, a missing lookup sends only the selected
text to Google Translate. The user can disable automatic supplementation and
invoke it using the in-page translation button. No API keys, learning records or article databases are
sent; requests omit credentials and referrers. That optional public endpoint may
be unavailable, rate-limited or blocked. The bundled dictionary works offline.
